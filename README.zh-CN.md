# HTML 可视化编辑器

一个基于 [GrapesJS](https://grapesjs.com/) 的浏览器端 HTML 可视化编辑器。项目采用单页面结构，无需前端构建工具，可直接用于本地 HTML 页面编辑、复杂表格搭建、HTML 导入和导出。

[English](README.md) | 简体中文

## 功能特性

- 基于 GrapesJS 的可视化拖拽编辑画布
- 组件库支持基础组件、布局组件、排版组件、表单组件、导航组件和表格组件
- 新建空白画布
- 导入 HTML 文件
  - 支持顶部“导入”按钮选择文件
  - 支持将 `.html` / `.htm` 文件拖入空编辑区
  - 保留导入文档中的原始 CSS、媒体查询和响应式样式
- 导出完整 HTML 文件
- 新窗口预览页面
- 查看并复制 HTML + CSS
- 撤销与重做
- 桌面、平板、手机设备预览切换
- 样式、图层、属性和表格工具面板
- 画布初始为空，不预置示例页面
- 空画布状态提供操作提示和 HTML 文件拖放区域
- 画布存在未导出修改时，刷新或关闭页面会进行提醒

## 复杂表格

编辑器内置复杂表格操作能力，支持：

- 复杂表头
- `rowspan` 行合并
- `colspan` 列合并
- Ctrl + 点击多选单元格
- 合并单元格
- 拆分单元格
- 插入或删除行
- 插入或删除列
- 跨行、跨列单元格处理
- 在单元格中插入嵌套表格

表格操作需要先在画布中选中 `td` 或 `th` 单元格，然后打开右侧“表格”面板。

## 快速开始

### 直接打开

双击打开 `index.html` 即可使用编辑器。

### 使用本地静态服务器

使用静态服务器运行更适合开发和测试。例如使用 Python：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

也可以使用 VS Code 的 Live Server 或其他静态文件服务器。

## 基本操作

### 创建页面

1. 点击顶部右侧的组件库按钮。
2. 从组件库中选择组件。
3. 将组件拖入画布。
4. 选中画布中的组件，在右侧样式、属性或图层面板中进行编辑。

选中画布组件后，组件库会自动隐藏，右侧会恢复样式面板。

### 导入 HTML

可以通过以下方式导入：

- 点击顶部“导入”按钮选择 HTML 文件；
- 在空编辑区直接拖入 HTML 文件。

导入时会读取 HTML 的 `body` 内容和 `style` 样式，并尽可能保留原始页面的 CSS 结构、媒体查询和响应式规则。

### 导出 HTML

点击“导出 HTML”后，编辑器会下载一个完整 HTML 文件，其中包含：

- HTML 页面结构
- GrapesJS 编辑产生的 CSS
- 导入页面保留的原始 CSS
- 响应式媒体查询

## 技术说明

- HTML5
- CSS3
- JavaScript
- GrapesJS
- `FileReader`：读取导入的 HTML 文件
- `DOMParser`：解析 HTML 文档结构
- GrapesJS Component API：管理画布组件
- GrapesJS CSS Composer：管理可编辑的基础 CSS 规则

项目不依赖 Node.js、npm 或前端构建流程，适合部署到任意静态文件服务器。

## 导入样式处理

导入完整网页时，复杂 CSS 如果全部交由 GrapesJS 重新解析，可能改变媒体查询、选择器优先级或原始页面布局。因此当前实现采用两部分处理方式：

1. 原始 CSS 直接注入画布，尽量保持导入页面的视觉效果；
2. 关键基础规则同步注册到 GrapesJS CSS Composer，使右侧样式面板可以读取和编辑对应值。

这可以兼顾导入页面的显示效果和可视化编辑能力。
